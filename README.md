## Ocean View Resort Reservation System

This project is a web-based reservation management system developed for the Advanced Programming module.

## Project Description

Ocean View Resort is a hotel reservation system that allows staff members to manage guest reservations efficiently. The system replaces manual reservation processes and helps prevent booking conflicts.

The system was developed using Java web technologies and follows a structured MVC-based architecture.

## Technologies Used

- Java
- JSP
- Servlets
- MySQL Database
- Apache Tomcat Server
- IntelliJ IDEA
- Git & GitHub

## System Features

The system includes the following functionalities:

- User Login Authentication
- Add New Reservation
- View Reservation Details
- Calculate and Print Bill
- Help Section for Users
- Logout Function

## System Structure

The project includes the following main components:

- Controller (Servlet classes)
- Model classes
- DAO classes for database operations
- JSP pages for user interfaces
- Database connection manager
